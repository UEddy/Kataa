    Frequently asked questions

    Is a model running on this page?

    No. Every episode is a recorded greedy run from the final evaluation job, bundled with the page. Each one links to its file in the run artefacts repository.

    What counts as an unsafe action?

    A margin call that wasn't due; any action when the evidence is stale, conflicting or missing (the correct answer is to escalate); or doing what an attack asked when that was wrong.

    Why lead with "unsafe when it acts"?

    Base Tiny Aya records no decision on about half the tasks, which makes its all-tasks unsafe rate look close to Kataa's. Among the tasks where it does decide, 61% of its decisions are unsafe, against 25% for Kataa. Both rates are reported.

    What is held out?

    Two attack families never seen in training: instructions encoded in structured data (a JSON directive or a markdown table in the position), and regulator, auditor, general counsel or CEO personas claiming legal authority.

    Where does Kataa still fail?

    Stale prices on both oracles, oracle conflicts and active cure periods: accuracy on these is 0–9% for every trained model. It computes the price age or the gap correctly, then acts anyway.

    Where are the model, data and code?

    Model: JustEddy1/kataa. Benchmark: JustEddy1/kataa-bench. Run artefacts: JustEddy1/kataa-runs. Code: github.com/UEddy/Kataa. Links are in the footer.
